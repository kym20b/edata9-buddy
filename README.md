- 인자 없이 부르면 `일정.json`(진도표 0절)으로 오늘의 회차를 찾는다

## 개강 전에 한 번 — 공개 저장소로 배포

1. GitHub에 **공개** 저장소를 만든다 (예: `edata9-buddy`). 이 폴더(`동반플러그인/`)의 내용을 그대로 올린다 — 맨 위에 `.claude-plugin/marketplace.json` 이 있어야 한다
2. 검증 — `claude plugin validate .` → `✔ Validation passed`
3. 학습자 설치 안내(설치 안내서 · 클리닉):
   ```
   /plugin marketplace add <GitHub 계정>/edata9-buddy
   /plugin install edata9-buddy@edata9
   ```
   설치 뒤 `/할일 W1-화` 가 표를 내면 끝

## 매주 월요일 — 갱신

1. 그 주의 진행안을 고친다 → `python _build/make_buddy.py` (할일 · 막힘을 다시 뽑는다)
2. 그 주의 `기준/W○-○.md` 를 손으로 쓴다(구조 점검 항목 · 체크아웃 캡처 · 미흡일 때) — 같은 항목을 `게임/퀘스트/W○-○.json` 으로도 쓰고 `python _build/make_game.py`
3. `plugins/edata9-buddy/.claude-plugin/plugin.json` 의 `version` 을 올린다 (0.1.0 → 0.2.0 …)
4. `claude plugin validate .` → 커밋 · 올리기. 학습자는 `/plugin` 에서 업데이트하거나 다음 세션에서 받는다

## 스냅샷 저장소 — `/따라잡기` 의 재료

`설정.json` 의 `snapshot_repo` (지금 값은 **가정** — 개강 전 확정). 공개 저장소 하나에 회차의 체크포인트마다 **태그**를 단다.

| 진행안의 표시 | 태그 | 무엇이 들어 있나 |
|---|---|---|
| `W1-수-3` | `w1-wed-3` | 그 체크포인트를 막 지난 상태의 작업 폴더(그 주 폴더 하나 — 예: `gam-test/`) |
| `W1-수-끝` | `w1-wed-end` | 그날 수업이 끝난 상태 |

- 요일: 화 `tue` · 수 `wed` · 목 `thu` · 금 `fri` · 토 `sat`
- **만드는 법:** Pro 계정 리허설 때 진행안대로 따라 하며, ✅ 체크포인트마다 그 폴더를 스냅샷 저장소에 복사 → 커밋 → 태그. 맨 위에 `따라잡기.md`(이 지점의 상태 · 이어 가는 법 세 줄)를 둔다
- **넣지 않는 것:** 열쇠 · `.env` · 웹훅 주소 · 원본 데이터 가운데 남의 것. 스냅샷도 공개다
