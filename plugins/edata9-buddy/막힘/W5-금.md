|---|---|---|---|
| 목요일 정의서가 없거나 여섯 개가 아니다 | 목요일 수업을 다 따라오지 못했다 | 강사가 공유하는 정답본의 `목요일_끝/metrics` 폴더와 `CLAUDE.md`를 덮어쓴다 | 강사 화면으로 따라간다 |

| 대시보드가 비어 있다 | 처음 몇 초는 데이터 엔진을 받는 중이다 | 잠시 기다린 뒤 새로 고친다 | «대시보드가 비어 있어. 원인을 찾아 고쳐줘» |
| 대시보드의 값이 카드와 다르다 | 대시보드가 정의서 말고 다른 계산을 쓴다 | «대시보드의 값이 카드와 달라. 대시보드가 정의서 말고 다른 계산을 쓰는지 찾아서 카드와 같은 계산을 쓰게 고쳐줘» | 정답본 `금요일_끝` 폴더의 앱 파일을 덮어쓴다 |
| 정의서를 고쳤는데 화면이 그대로다 | 새로 고치지 않았거나 정의 문장만 고치고 SQL을 고치지 않았다 | `Ctrl+F5`로 새로 고치고, 정의서의 SQL도 바뀌었는지 본다 | «활성 고객 비율 정의서의 문장과 SQL이 같은 기준인지 확인해줘» |
| 기준을 되돌릴 곳을 못 찾겠다 | 문장과 SQL 두 곳을 고쳐야 한다 | «활성 고객 비율 정의서의 로그인 기준을 8회로 되돌려줘. 문장과 SQL 둘 다» | 정답본 `목요일_끝/metrics`의 그 정의서를 덮어쓴다 |
| 카드에 «계산 오류»가 뜬다 | 정의서의 SQL이 실패했다 | «카드에 계산 오류가 나와. 원인을 찾아 정의서를 고쳐줘» | 강사 화면으로 따라간다 |
