# W9-금 기준 — 36장 남의 눈으로 본다 · 마켓플레이스

체크아웃 캡처: 마지막 포트폴리오(다른 기기) + 동료 꾸러미를 읽은 결과 + 동료 스킬을 쓴 화면

## 점검 항목

| 항목 | 통과 조건 |
|---|---|
| 플레이북 | `my-wiki/판단기준.md` 에 «통신사» · «해지» · «요금제» 같은 데이터 이름이 남아 있지 않다 — 남은 줄 수를 알려 준다 |
| 지적 처리 | `my-wiki/log/` 에 지적 표가 있다 — «사정을 모른다» 같은 분류가 들어 있다 |
| 내 마켓플레이스 | `my-plugins` 의 원격이 `github.com` 이다 |
| 동료 것을 읽었다 | `edata9-work/_읽기/` 가 있다 — 못 찾으면 «확인 불가» |
| 설치한 꾸러미 | 확인 불가 — 캡처로 확인 |
