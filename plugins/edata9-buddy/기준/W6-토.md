# W6-토 기준 — 혼자 해보기 · 내 가상 실험

체크아웃 캡처: 내 가상 실험의 세 판정, 또는 «검출 불가» 기록 + 노션 «6주» 장

## 점검 항목

| 항목 | 통과 조건 |
|---|---|
| 내 가상 실험 | `my-wiki/decisions/` 에 내 업무의 가상 실험 기록이 있다 — «가정»이라는 말이 들어 있다 |
| 판정 | 그 기록에 «실행할 수 있음» 또는 «검출 불가» |
| 판단 기준 | `my-wiki/판단기준.md` 에 «6주» 장이 있다 |
| 노션 | 이어져 있으면 «6주»를 찾아본다. 아니면 «확인 불가(노션 미연결)» |

## 미흡일 때

- 실제 회사 숫자가 보인다 → 지운다. 가정이라고 적은 숫자만(혼자 해보기 1 · 3번)
