# W1-목 기준 — 3장 공개 데이터로 문항을 만든다

체크아웃 캡처: **내 주제의 문항이 로컬에서 뜬 화면** (최소: 목업 주제의 문항 하나를 내 계산으로 바꾼 화면)

## 점검 항목

| 항목 | 통과 조건 |
|---|---|
| 내 문항 | `gam-test/topics.json` 의 주제가 목업의 열 개보다 많거나, `topics/` 의 문항 파일 하나가 목업과 다르다 |
| 근거가 붙었다 | 새로 넣은 문항마다 `basis` 칸이 비어 있지 않다 |
| 원본은 올라가지 않게 | `gam-test/.gitignore` 에 `data/` 가 있다 |
| 원본 | `gam-test/data/raw/` 에 파일이 있다 — 최소 완주라면 «확인 불가»로 둔다 |

## 미흡일 때

- 출처를 못 찾았다 → 최소 완주 경로: 목업 주제의 문항 하나만 내 계산으로
- 원본이 너무 커서 막혔다 → `/따라잡기 W1-목-3` (견본 원본이 들어 있다)
