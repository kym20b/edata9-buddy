# W4-금 기준 — 16장 브라우저 안의 데이터베이스

체크아웃 캡처: **Vercel 주소**의 내 질문(판단 포인트 · SQL · 표) + 처방 한 장(`인사이트_금.md`) + 포트폴리오 네 번째 칸

## 점검 항목

| 항목 | 통과 조건 |
|---|---|
| 내 질문 | `sql-window/questions.json` 의 질문이 목업의 아홉 개보다 많다 |
| 판단 포인트 · 확인할 값 | 새 질문마다 `judge` 가 비어 있지 않고 `check` 가 둘이다 |
| 원래 질문 | 목업의 아홉 질문이 그대로 있다 |
| 쓰기 전에 | `sql-window/README.md` 에 «쓰기 전에» 절이 있다 |
| 처방 한 장 | `sql-window/인사이트_금.md` 가 있고 «처방» 칸이 있다 (기술 · 진단 · 예측 · 처방 · 효과는 어떻게 보나) |
| 열쇠가 코드에 없다 | `sql-window` 의 `.js` · `.py` · `.json` 어디에도 `AIza` 로 시작하는 값이 없다 (찾으면 파일 이름만) |
| 원격 · 배포 제외 | 원격이 `github.com` 이고, `.vercelignore` 에 `tools/` · `.claude/` · `.mcp.json` 이 있다 |
| 포트폴리오 | `portfolio/portfolio.json` 에 카드가 네 장 이상 |

## 미흡일 때

- 처방 한 장이 없다 → 교안 7절. 앞의 세 칸은 화 · 수 · 목 인사이트에서 한 줄씩, 처방은 내가 쓴다
- 확인할 값이 하나뿐이다 → 16-7 요구사항 4
- 열쇠가 코드에 있다 → **그 열쇠를 먼저 폐기**(2부 7-6), 그다음 지운다
