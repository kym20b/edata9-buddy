# W4-목 기준 — 15장 조인과 부풀려지는 숫자

체크아웃 캡처: 계획 모드의 계획(«붙인 뒤 몇 줄»이 숫자로) + 실행 결과의 줄 수

## 점검 항목

| 항목 | 통과 조건 |
|---|---|
| 조인 규칙 | `my-wiki/decisions/` 에 오늘 날짜쯤의 결정 기록이 있고, 본문에 `JOIN` 또는 «붙이» 와 «몇 대 몇» 또는 «줄 수»가 있다 |
| INNER의 이유 | 그 기록에 `INNER` 가 있으면, 같은 줄이나 다음 줄에 «잃어도» 같은 이유가 있다 |
| 계획 화면 | 확인 불가 — 캡처로 확인 |

## 미흡일 때

- 결정 기록이 없다 → 책 15-10. 견본은 `/따라잡기 W4-목-4`
- INNER에 이유가 없다 → 15-4의 질문 «한쪽에만 있는 줄을 잃어도 되는가?»
