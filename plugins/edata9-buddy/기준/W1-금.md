## 점검 항목

| 항목 | 통과 조건 |
|---|---|
| 저장 지점 | `gam-test` 가 git 저장소이고 커밋이 하나 이상 있다 |
| GitHub | `gam-test` 의 원격이 `github.com` 이다 |
| 포트폴리오 첫 칸 | `edata9-work/portfolio/portfolio.json` 의 `cards` 에 하나 이상 있고, 그 칸의 `judgment` 가 비어 있지 않다 |
| 링크 | 그 칸의 `url` 에 `vercel.app` 이 들어 있다 |
| 폰에서 열리는가 | 확인 불가 — 캡처로 확인 |
