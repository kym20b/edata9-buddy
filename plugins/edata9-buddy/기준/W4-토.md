# W4-토 기준 — 혼자 해보기 · 내 질문으로 창을 채운다

체크아웃 캡처: 내 창의 «준비한 질문» — 표 둘 이상을 붙인 질문 하나 + 노션 «4주» 장

## 점검 항목

| 항목 | 통과 조건 |
|---|---|
| 내 질문 | `sql-window/questions.json` 에 목업보다 질문이 셋 이상 많다 — 최소 완주라면 하나 |
| 붙인 질문 | 새 질문의 `sql` 가운데 `JOIN` 이 든 것이 하나 이상 |
| 판단 기준 | `my-wiki/판단기준.md` 에 «4주» 장이 있다 |
| BigQuery MCP | 확인 불가 — 도전이라 미흡으로 치지 않는다 |
| 노션 | 이어져 있으면 «4주»를 찾아본다. 아니면 «확인 불가(노션 미연결)» |

## 미흡일 때

- 붙인 질문이 없다 → 혼자 해보기 2번. 15-10의 내 조인 규칙을 따른다
