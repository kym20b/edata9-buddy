# W4-토 기준 — 토요일 프로젝트 · 내 주제의 표 여러 개로 내 창을

체크아웃 캡처: 내 창(`my-window`)의 «준비한 질문» — 표 둘 이상을 붙인 질문 하나 + 정답과 대조한 표

## 점검 항목

| 항목 | 통과 조건 |
|---|---|
| 내 표 | `my-window/data/` 에 parquet 이 둘 이상 있고, 목업의 표 이름(`customers` · `support_tickets` 등)이 아니다 |
| 정답은 따로 · 잠금 | `my-window/tools/answer/` 에 파일이 하나 이상 있고, `my-window/.claude/settings.json` 의 deny 에 `tools/answer` 가 든 줄이 있다 |
| 한 줄은 내가 | `my-window/schema.json` 의 표마다 `grain` 이 비어 있지 않다 |
| 붙인 질문 | `my-window/questions.json` 에 질문이 하나 이상 있고, 그 가운데 `sql` 에 `JOIN` 이 든 것이 하나 이상 — 최소 단계라면 «확인 불가 — 계획 대조 캡처로» |
| 토요일 기록 | `my-wiki/log/` 에 «토요일 프로젝트»가 적힌 기록이 있다 — 최소 단계라면 미흡으로 치지 않는다 |

## 미흡일 때

- 정답 잠금이 없다 → 교안 2단계. 설정을 바꾼 뒤에는 `/clear`
- 붙인 질문이 없다 → 교안 5 · 6단계. 계획대로 먼저 묶고 붙인 SQL을 넣는다
- `my-window` 가 없다 → `sql-window` 에 했다면 그대로 둬도 된다. 다음 토요일 전에 `w4-sql-window` 를 다시 복사해 이름을 `my-window` 로
