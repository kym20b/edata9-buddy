# W5-금 기준 — 정의서를 AI와 함께 쓰고, 배포 전에 점검한다 (월 이탈률)

체크아웃 캡처: 배포한 URL의 «월 이탈률» 카드 + 5절의 답 첫 줄 + 판단 한 장 «5주»

## 점검 항목

| 항목 | 통과 조건 |
|---|---|
| 월 이탈률 정의서 | `edata9-work/metric-dictionary/metrics/월_이탈률.json` 이 있고 `metrics/index.json` 에 이름이 있다 |
| 월초 고객 분모 | 그 정의서에 «월초» 가 들어 있다 — 분모가 «그 달 시작 때 있던 고객»이다 |
| 앱이 아는 자리표시자 | 그 정의서에 `{prev_month_end}` 가 없다 — 앱은 `{month}` · `{month_start}` · `{month_end}` 만 안다 |
| 검수 스킬 | `metric-dictionary/.claude/skills/validate-data/SKILL.md` 가 있다 |
| 배포 제외 | `metric-dictionary/.vercelignore` 에 `tools/` 와 `.claude/` 가 있다 |
| 원격 | `metric-dictionary` 의 git 원격이 `github.com` 이다 |
| 판단 한 장 | `my-wiki/판단기준.md` 에 «5주» 장이 있다 |
| 포트폴리오 | `portfolio/portfolio.json` 에 «내가 내린 판단»이 든 카드가 다섯 장 이상 |
| 배포한 URL의 카드 · 대화의 답 | 화면과 대화는 «확인 불가 — 캡처로 확인» |

## 미흡일 때

- 정의서가 없다 → 교안 4절 프롬프트. 파일 이름은 `월_이탈률.json`
- 카드가 «계산 오류»다 → 정의서에 `{prev_month_end}` 같은 앱이 모르는 자리표시자가 있다. 교안 4절의 «카드에 계산 오류가 나와…» 말을 보낸다
- 원격이 없다 → 교안 8절 프롬프트(GitHub 공개 저장소로 올리기). 올리기 전에 7절의 점검을 먼저 한다
- 판단 한 장이 없다 → 교안 10절 프롬프트. 정의서에서 내가 정한 것만 한 줄씩 옮긴다
