# W5-금 기준 — 시맨틱 레이어: 정의서로 대시보드를 만들고 배포한다

체크아웃 캡처: 배포한 URL의 대시보드 + 5절의 새 대화 답 첫 줄 + 판단 한 장 «5주»

## 점검 항목

| 항목 | 통과 조건 |
|---|---|
| 정의서 여섯 | `edata9-work/metric-dictionary/metrics/` 에 정의서가 여섯 개 이상이다 — `index.json` 을 빼고 셀 때 |
| 대시보드 탭 | `metric-dictionary/index.html` 에 «대시보드» 탭이 있다 |
| 배치 파일 | `metric-dictionary/dashboard.json` 이 있고 지표 id가 하나 이상 적혀 있다 |
| 정의서를 읽는 대시보드 | `metric-dictionary/app.js` 가 `dashboard.json` 을 읽는다 |
| 기준 되돌리기 | 활성 고객 비율 정의서의 로그인 기준이 «8회»다 — 5절에서 10회로 바꿔 본 뒤 되돌렸다. 10회로 남아 있으면 미흡 |
| 배포 제외 | `metric-dictionary/.vercelignore` 에 `tools/` 와 `.claude/` 가 있고, `data/` · `metrics/` · `dashboard.json` 은 없다 |
| 원격 | `metric-dictionary` 의 git 원격이 `github.com` 이다 |
| 판단 한 장 | `my-wiki/판단기준.md` 에 «5주» 장이 있다 |
| 포트폴리오 | `portfolio/portfolio.json` 에 «내가 내린 판단»이 든 카드가 다섯 장 이상 |
| 배포한 URL의 대시보드 · 대화의 답 | 화면과 대화는 «확인 불가 — 캡처로 확인» |

## 미흡일 때

- 정의서가 여섯이 아니다 → 강사가 공유하는 정답본의 `목요일_끝/metrics` 폴더와 `CLAUDE.md` 를 덮어쓴다
- 대시보드 탭이나 `dashboard.json` 이 없다 → 교안 3절(구성안) 다음 4절 프롬프트. 따라오지 못했으면 정답본 `금요일_끝` 폴더의 `app.js` · `index.html` · `style.css` · `dashboard.json` 을 덮어쓴다
- 활성 기준이 10회로 남아 있다 → «활성 고객 비율 정의서의 로그인 기준을 8회로 되돌려줘. 문장과 SQL 둘 다»라고 보낸다
- `.vercelignore` 에 `data/` · `metrics/` · `dashboard.json` 이 들어 있다 → 그 줄을 뺀다. 이 앱은 세 가지를 함께 배포한다
- 원격이 없다 → 교안 6절(나가는 파일을 확인한 뒤 GitHub 공개 저장소로 올리고 Vercel에서 배포)
- 판단 한 장이 없다 → 교안 8절 프롬프트. 이번 주에 내가 정한 것을 다른 데이터에도 쓸 수 있는 문장으로(숫자 · 컬럼 이름 없이)
