# W5-금 기준 — 20장 세 AI에게 같은 지표를 묻고, 정의서와 함께 공유한다

체크아웃 캡처: Vercel URL의 카드(정의 한 문장 · 분자 ÷ 분모) + 노션 «지표 사전» 첫 행 + 포트폴리오 5주 카드

## 점검 항목

| 항목 | 통과 조건 |
|---|---|
| 카드를 내 정의로 | `metric-card/metrics/이탈률.json` 이 목업과 다르다 — `purpose` 나 기본 분모를 내 정의서대로 바꿨다 |
| 세 AI 덧붙임 | `my-wiki/decisions/` 의 이탈률 정의서에 «세 AI» 가 든 덧붙임이 있다 |
| 원격 | `metric-card` 의 원격이 `github.com` 이다 |
| 배포 제외 | `metric-card/.vercelignore` 에 `tools/` 와 `.claude/` 가 있다 |
| 포트폴리오 | `portfolio/portfolio.json` 에 «내가 내린 판단»이 든 카드가 다섯 장 이상 |
| 판단 한 장 | `my-wiki/판단기준.md` 에 «5주» 장이 있다 |
| 노션 지표 사전 | 노션이 이어져 있으면 «지표 사전»을 찾아본다. 아니면 «확인 불가(노션 미연결)» |

## 미흡일 때

- 노션 «지표 사전»의 분모가 비었다 · Claude가 «어느 분모?»를 물었다 → 프롬프트에 «../my-wiki/decisions/ 의 이탈률 정의서에서» 경로를 넣는다(교안 12절)
- 세 AI 숫자를 못 셌다(node 오류) → «파이썬으로 세어줘»(교안 3절)
- 노션이 안 이어진다 → 3주 금 «노션 연결» 순서 → `/mcp`
