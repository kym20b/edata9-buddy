# W5-금 기준 — 20장 세 AI에게 같은 지표를 묻는다 · 노션 지표 사전

체크아웃 캡처: Vercel 카드(정의 한 문장 · 분자 ÷ 분모) + 노션 «지표 사전» 첫 줄

## 점검 항목

| 항목 | 통과 조건 |
|---|---|
| 원격 | `metric-card` 의 원격이 `github.com` 이다 |
| 배포 제외 | `metric-card/.vercelignore` 에 `tools/` 와 `.claude/` 가 있다 |
| 서버 함수 없음 | `metric-card/api/` 가 없다 — 열쇠도 서버도 없이 돈다 |
| 포트폴리오 | `portfolio/portfolio.json` 에 카드가 다섯 장 이상 |
| 노션 지표 사전 | 노션이 이어져 있으면 «지표 사전»을 찾아본다. 아니면 «확인 불가(노션 미연결)» |
