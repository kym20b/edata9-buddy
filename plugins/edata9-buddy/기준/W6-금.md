# W6-금 기준 — 규모 계산과 배포: 판정기에 «필요 인원 · 기간» 탭을 더해 인터넷에 올린다

체크아웃 캡처: 배포한 URL의 «필요 인원 · 기간» 탭 + 개념 정리 아티팩트 + 판단 한 장 «6주»

## 점검 항목

| 항목 | 통과 조건 |
|---|---|
| 계산 탭 | `edata9-work/w6-ab-judge/index.html` 에 «필요 인원 · 기간» 탭이 있다 |
| 엔진을 쓰는 탭 | `w6-ab-judge/app.js` 가 `judge.js` 의 `sampleSize` 를 쓴다 — 화면 코드에 새 공식을 적지 않았다 |
| 기준값 되돌리기 | `w6-ab-judge/rules.json` 의 `mde_relative` 가 `10` 이다 — 6절에서 15로 바꿔 본 뒤 되돌렸다. 15로 남아 있으면 미흡 |
| 배포 제외 | `w6-ab-judge/.vercelignore` 에 `tools/` 와 `.claude/` 가 있고, `rules.json` · `data/` · `judge.js` 는 없다 |
| 원격 | `w6-ab-judge` 의 git 원격이 `github.com` 이다 |
| 판단 한 장 | `my-wiki/판단기준.md` 에 «6주» 장이 있다 |
| 포트폴리오 | `portfolio/portfolio.json` 에 «내가 내린 판단»이 든 카드가 여섯 장 이상 |
| 배포한 URL의 탭 · 개념 정리 · 회의 문장 | 화면과 대화는 «확인 불가 — 캡처로 확인» |

## 미흡일 때

- 탭이 없다 → 교안 4절 프롬프트. 따라오지 못했으면 강사가 공유하는 정답본 `금요일_끝` 폴더의 `index.html` · `app.js` · `style.css` 를 덮어쓴다
- `app.js` 에 공식이 따로 있다 → «탭이 judge.js 의 sampleSize 를 쓰게 고쳐줘. 판정 화면은 그대로 둬»
- `mde_relative` 가 15로 남아 있다 → «mde_relative 를 10 으로 되돌리고 커밋해서 올려줘». 수요일 가설의 기준과 맞추기 위해서다
- `.vercelignore` 에 `rules.json` · `data/` · `judge.js` 가 들어 있다 → 그 줄을 뺀다. 이 앱은 브라우저가 세 파일을 읽어 계산하므로 함께 배포한다
- 원격이 없다 → 교안 5절(나가는 파일을 확인한 뒤 GitHub 비공개 저장소로 올리고 Vercel에서 배포)
- 판단 한 장이 없다 → 교안 8절 프롬프트. 이번 주에 정한 것을 다른 데이터에도 쓸 수 있는 문장으로(숫자 · 컬럼 이름 없이)
