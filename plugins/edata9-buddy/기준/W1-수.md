# W1-수 기준 — 2장 AI에게 화면을 시킨다

체크아웃 캡처: **내 제목 · 색으로 바뀐 첫 화면** (폰 크기)

## 점검 항목

| 항목 | 통과 조건 |
|---|---|
| 내 제목 | `gam-test/topics.json` 의 `title` 이나 `index.html` 의 제목이 목업의 «감 테스트»에서 바뀌었다 |
| 시안 | `gam-test/시안.png` 가 있다 (교안의 예시 시안을 저장해도 통과) |
| 문항 파일은 그대로 | `gam-test/topics/` 아래 문항 파일이 열 개 이상 있다 — 화면을 바꾸다 지워지지 않았다 |

## 미흡일 때

- 제목이 그대로다 → 책 2-8 프롬프트의 «제목과 부제를 [내 문장]으로»
- 채점이 이상해졌다 → «방금 바꾼 것을 되돌려줘», 또는 `/따라잡기 W1-수-3`
