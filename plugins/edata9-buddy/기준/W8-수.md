# W8-수 기준 — 30장 AI 해설에 선을 긋는다 · 헤드리스

체크아웃 캡처: `out/점검.md` — `claude -p` 의 표 + 내 판정

## 점검 항목

| 항목 | 통과 조건 |
|---|---|
| 목록을 키웠다 | `rules.json` 의 `banned` 네 종류 가운데 하나 이상이 목업보다 길다 |
| 헤드리스 점검 | `briefing-bot/out/점검.md` 가 있다 |
| 내 판정 | 그 파일이나 `my-wiki/log/` 에 «맞다» · «아니다» 같은 내 판정이 있다 — 못 찾으면 «확인 불가 — 캡처로» |
| 열쇠가 파일에 없다 | `briefing-bot` 의 파일 어디에도 `AIza` 로 시작하는 값이 없다 (찾으면 파일 이름만) |

## 미흡일 때

- 점검 파일이 없다 → 30-10의 `--allowedTools "Write"`
- 열쇠가 파일에 있다 → **그 열쇠를 먼저 폐기**(2부 7-6), 그다음 지운다
