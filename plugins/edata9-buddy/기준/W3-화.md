# W3-화 기준 — 9장 한 줄이 무엇인가

체크아웃 캡처: 목업 정리기의 **진단 화면** + 파일 넷의 «한 줄이 무엇인가» 메모

## 점검 항목

| 항목 | 통과 조건 |
|---|---|
| 목업 | `edata9-work/cleaner/` 에 `index.html` · `clean.js` 가 있다 |
| 지저분한 파일 | `edata9-work/messy/` 에 파일 넷(영업실적 · 마케팅집행 · 상담이력 · 교육이수로그)이 있다 — `cleaner` 안이 아니라 옆에 |
| 원본은 그대로 | `messy/` 의 파일이 고쳐지지 않았다 (수정 시각이 배포 때와 같으면 통과, 모르면 «확인 불가») |
| 한 줄 메모 | 위키나 작업 폴더에 파일 넷의 «한 줄» 메모가 있으면 통과. 못 찾으면 «확인 불가 — 캡처로» |

## 미흡일 때

- 진단이 안 뜬다 → 로컬 서버로 연다(1-9). `/따라잡기 W3-화-1`
- 한 줄을 못 정했다 → 9-5의 «후보를 적고, 줄 수와 서로 다른 값의 개수를 세어 맞춰 본다»
