# W8-금 기준 — 32장 봇을 가동한다 · 노션 보관

체크아웃 캡처: 디스코드 브리핑(내 발견 한 줄) + 노션 «브리핑 보관함»의 이번 주 장

## 점검 항목

| 항목 | 통과 조건 |
|---|---|
| 내 발견 | `briefing-bot/notes.md` 의 주석 바깥 글에 숫자가 둘 이상 있다 — 비교 대상이 있다는 뜻 |
| 원인은 후보로 | 그 글에 «때문»이 있으면 같은 줄에 «확인 안 됨»이 있다 |
| 올렸다 | `notes.md` 를 고친 커밋이 원격에 있다 |
| 포트폴리오 | `portfolio/portfolio.json` 에 카드가 여덟 장 이상 |
| 노션 보관함 | 이어져 있으면 «브리핑 보관함»을 찾아본다. 아니면 «확인 불가(노션 미연결)» |

## 미흡일 때

- 원인을 단정했다 → 32-6. «확인 안 됨»을 붙이거나 후보로 바꾼다
