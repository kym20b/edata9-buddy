# W3-금 기준 — Claude 없는 동료에게 건넨다 · 노션 주간 노트

체크아웃 캡처: **Vercel 주소**의 Network 탭(규칙 파일 요청뿐) + 포트폴리오 세 번째 칸 + 노션 «EDATA 주간 노트»

## 점검 항목

| 항목 | 통과 조건 |
|---|---|
| 규칙 파일 | `cleaner/rules/` 에 이름이 `상담원장` 으로 시작하는 `.json` 이 있다 |
| 한계 기록 | `my-wiki/limits/` 에 `.md` 파일이 하나 이상 있다 (`README.md` 는 빼고 센다) |
| 원격 | `cleaner` 의 원격이 `github.com` 이다 |
| 저장소에 데이터 없음 | `git -C cleaner ls-files` 목록에 `tools/answer/` · `정리본/` · `진단/` 아래 파일이 하나도 없다 |
| 배포 제외 | `cleaner/.vercelignore` 에 `tools/` 가 있다 — 정답은 배포되지 않는다 |
| 서버 함수 없음 | `cleaner/api/` 폴더가 없다 — 이 도구는 서버 없이 돈다 |
| 포트폴리오 | `portfolio/portfolio.json` 에 카드가 세 장 이상 있다 |
| 판단 기준 | `my-wiki/판단기준.md` 에 «3주» 장이 있다 |
| Network 확인 | 확인 불가 — 캡처로 확인 |
| 노션 | 이어져 있으면 «EDATA 주간 노트»에 «3주»가 있는지 본다. 아니면 «확인 불가(노션 미연결) — 캡처로» |

## 미흡일 때

- 규칙 파일이 없다 → 교안 2절. 목요일 결정 기록을 규칙 파일로 옮긴다
- 한계 기록이 없다 → 교안 5절 끝. 정답과 대조한 결과를 `limits/` 에 남긴다
- 저장소에 정답 · 정리본 · 진단이 들어 있다 → 교안 6절의 프롬프트. 아직 올리지 않았다면 이력을 새로 시작하게 한다. 이미 올렸다면 강사에게 알린다
- 정답 폴더가 배포에 들어간다 → `.vercelignore` 에 `tools/` 를 넣고 다시 올린다
- 포트폴리오 칸이 없다 → 교안 7절 끝
- «3주» 장이 없다 → 교안 8절의 판단 한 장 프롬프트
- 노션이 안 이어진다 → 교안 8절 «노션 잇기». 토요일 쉬는 시간에 해도 된다

## 보지 않는 것

- 정리기의 숫자가 맞는지는 보지 않는다. 교안 3절 · 5절의 숫자와 내가 견준다
- 정답 파일(`tools/answer/`)은 열지 않는다
