# W6-목 기준 — 23장 실험의 함정 · 서브에이전트 `통계검산관`

체크아웃 캡처: **`@agent-통계검산관`** 의 숫자와 판정기 숫자를 나란히 놓은 표

## 점검 항목

| 항목 | 통과 조건 |
|---|---|
| 내 기준 | `ab-judge/rules.json` 의 `owner` 에 사람 이름이 있고, 기준마다 `why` 가 비어 있지 않다 |
| 판정기는 그대로 | `ab-judge/judge.js` 가 고쳐지지 않았다 (모르면 «확인 불가») |
| 검산관 | `ab-judge/.claude/agents/통계검산관.md` 가 있다 — 이름은 느슨하게 본다 |
| 맨 위 | 그 파일 맨 위에 `name:` · `description:` 이 있다. `tools:` 가 있으면 `Bash` 가 들어 있다 |
| 열지 않을 파일 | 본문에 `judge.js` 가 «열지» 같은 말과 함께 있다 |
| 판정하지 않는다 | 본문에 «판정하지» 또는 같은 뜻의 줄이 있다 |
