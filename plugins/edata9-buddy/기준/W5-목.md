# W5-목 기준 — 19장 정의서만 고치면 숫자가 바뀐다 · 둘째 스킬 `지표`

체크아웃 캡처: 정의서를 바꿔 달라진 카드 + `/지표 …` 가 비워 둔 요소 때문에 **멈춘** 화면 + `인사이트_목.md`

## 점검 항목

| 항목 | 통과 조건 |
|---|---|
| 계산은 그대로 | `metric-card/metric.js` 가 목업과 같다 — 무엇을 셀지는 정의서에서 바꾼다 |
| 스킬 | `metric-card/.claude/skills/지표/SKILL.md` 가 있다 |
| 내가 부를 때만 | 그 파일 맨 위에 `disable-model-invocation: true` 가 있다 |
| 멈출 조건 | 본문에 «멈» 이 들어간 줄이 있고, 그 아래 조건이 둘 이상 |
| 대신 정하지 않을 것 | 본문에 «분모» 와 «최소 표본» 이 «정하지 않» 과 함께 나온다 |
| 인사이트 | `metric-card/인사이트_목.md` 에 «본 것» · «검증» · «그래서» · «확인 안 된» 이 모두 있다 |

## 미흡일 때

- 스킬이 스스로 불린다 → 맨 위 `disable-model-invocation: true` (교안 7절)
- 스킬이 빈 요소를 채워 버린다 → 견본 `정답본/w5-metric-card/.claude/skills/지표/SKILL.md` 의 «멈춤 조건» · «대신 정하지 않을 것» 절과 비교
- `metric.js` 를 고쳤다 → 되감기. 정의서만 고친다(교안 3 · 4절)
- 카드 기본 숫자가 안 바뀐다 → 옛 목업(카드가 프리셋 A로 열린다). 새 zip
