# W5-목 기준 — 19장 정의서만 고치면 바뀐다 · 둘째 스킬 `지표`

체크아웃 캡처: `/지표 …` 가 비워 둔 요소 때문에 **멈춘** 화면

## 점검 항목

| 항목 | 통과 조건 |
|---|---|
| 내 정의 | `metric-card/metrics/이탈률.json` 의 `presets` 가 목업의 다섯(A~E)보다 많다 |
| 주인 | 그 파일의 `owner` 에 사람 이름이 있다 |
| 계산은 그대로 | `metric-card/metric.js` 에 «이탈»이라는 말이 없다 — 무엇을 셀지는 코드에 없어야 한다 |
| 스킬 | `metric-card/.claude/skills/지표/SKILL.md` 가 있다 |
| 내가 부를 때만 | 그 파일 맨 위에 `disable-model-invocation: true` 가 있다 |
| 멈출 조건 | 본문에 «멈» 이 들어간 줄이 있고, 그 아래 조건이 둘 이상 |

## 미흡일 때

- 스킬이 스스로 불린다 → 맨 위 `disable-model-invocation: true` (19-2)
- `metric.js` 를 고쳤다 → 되감기. 정의서만 고친다(19-3)
