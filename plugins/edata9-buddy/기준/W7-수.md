# W7-수 기준 — 26장 앱이 데이터를 거부하게 · Claude에게도 게이트

체크아웃 캡처: **«고친 직후 검사 — … 검사가 어긋났습니다»** + `/hooks` 의 PostToolUse

## 점검 항목

| 항목 | 통과 조건 |
|---|---|
| 검사 규칙 | `my-report/pipeline/validate.py` 에 «★ 여기를 채웁니다»가 남아 있지 않다 |
| 깨뜨린 사본 | `my-report/data_broken/` 이 있다 |
| 게이트 1 기록 | `my-report/runs/` 에 실행 기록이 하나 이상 있다 |
| 훅 | `my-report/.claude/settings.json` 의 `hooks.PostToolUse` 에 `after_edit.py` 를 부르는 훅이 있고, matcher 에 `Edit` 가 들어 있다 |
| 훅 프로그램 | `my-report/.claude/hooks/after_edit.py` 가 있다 |
| 검사는 그대로 | `config.py` 의 `VALID_TO` 가 시험 값(2025-06-30)으로 남아 있지 않다 — 남아 있으면 «되감기 안 함»으로 알린다 |

## 미흡일 때

- 훅이 없다 → 26-12. `/따라잡기 W7-수-4`
- `VALID_TO` 가 2025-06-30 이다 → 되감기(3-12) 또는 원래 값으로
