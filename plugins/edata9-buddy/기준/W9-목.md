# W9-목 기준 — 35장 발표 자료

체크아웃 캡처: Gamma 슬라이드의 첫 장 + 3분 원고를 소리 내어 읽은 시간

## 점검 항목

| 항목 | 통과 조건 |
|---|---|
| 원고 | `portfolio/` 나 `my-wiki/` 에 발표 원고 파일이 있다 — 이름은 느슨하게 본다(«원고» · «발표»). 못 찾으면 «확인 불가 — 캡처로» |
| 결론이 먼저 | 원고의 첫 단락에 제안 문장이 있다 |
| 요청 | 원고에 «주십시오» · «승인» 같은 요청이 있다 |
| 슬라이드 · 도식 | 확인 불가 — 캡처로 확인 |
