# W6-수 기준 — 퍼널과 가설: 고칠 곳을 고르고, 틀릴 수 있게 써서 노션에 남긴다

체크아웃 캡처: 아티팩트의 기기 드릴다운 + 노션 «실험 관리» 데이터베이스 + 9절 답의 첫 줄

## 점검 항목

| 항목 | 통과 조건 |
|---|---|
| 작업 폴더 | `edata9-work/funnel-hypothesis/` 가 있고, 옆에 5주의 `metric-dictionary/data/` 가 있다 |
| 공식 스킬 둘 | `funnel-hypothesis/.claude/skills/analyze/SKILL.md` 와 `funnel-hypothesis/.claude/skills/write-query/SKILL.md` 가 있다 |
| 노션 «실험 관리» | 노션이 이어져 있으면 «실험 관리» 데이터베이스가 있고, 행이 하나 이상이며 그 행에 성공 기준 · 반증 기준 · 상태가 채워져 있는지 읽기만 해서 본다. 노션이 이어져 있지 않으면 «확인 불가 — 캡처로 확인» |
| `/analyze` 의 답 · 가설 · 측정 쿼리 · 새 대화의 답 | 대화는 «확인 불가 — 캡처로 확인» |

## 미흡일 때

- 스킬이 없다 → 교안 3절 설치 프롬프트. «쓰기 권한이 허용되지 않았다»로 끝났으면 권한 요청에서 `.claude/skills/analyze` · `.claude/skills/write-query` 경로를 보고 Yes를 누른 뒤 «마저 설치해줘». 설치 뒤에는 새 대화를 연다
- 노션 데이터베이스가 없다 → 교안 7절. `/mcp` 에 `claude.ai Notion` 이 ✓ Connected인지 먼저 본다
- 행에 반증 기준이 비어 있다 → 교안 5절 가설 프롬프트를 다시 보내고, «반증 기준을 노션 행에 채워줘»
