체크아웃 캡처: 다른 기기에서 연 Streamlit 주소 — 맨 위 카드 + 감춘 달의 이유 + 포트폴리오 일곱 번째 칸

## 점검 항목

| 항목 | 통과 조건 |
|---|---|
| 못 믿을 조건 | `my-report/pipeline/trust.py` 에 «★ 여기를 채웁니다»가 남아 있지 않다 |
| 데이터 예외 | `my-report/.gitignore` 에 parquet 을 올리는 예외(`!` 로 시작하는 줄)와 그 이유 주석이 있다 |
| 비밀 · 기록은 그대로 | 같은 파일에 `.env` · `secrets.toml` · `runs/` 제외가 있다 |
| 원격 | `my-report` 의 원격이 `github.com` 이다 |
| 포트폴리오 | `portfolio/portfolio.json` 에 카드가 일곱 장 이상 |
| Streamlit 주소 | 확인 불가 — 캡처로 확인 |
