# W3-목 기준 — 11장 처리 규칙과 두 번 돌려도 같은 결과

체크아웃 캡처: **«두 번 돌려도 같은 결과»**가 뜬 화면 + 규칙 하나의 `why`

## 점검 항목

| 항목 | 통과 조건 |
|---|---|
| 규칙 파일 | `cleaner/rules/교육이수로그.json` 이 목업과 다르다 (바뀐 곳이 있다) |
| 이유 | 그 파일의 `columns` 마다 `why` 가 비어 있지 않다 |
| 주인 | `owner` 에 사람 이름이 있다 — 이름은 느슨하게 본다 |
| 저장 지점 | `cleaner` 에 규칙을 고친 커밋이 있다 (저장소가 아직 없으면 «확인 불가 — 금요일에 만든다») |

## 미흡일 때

- 이유가 비었다 → 책 11-7. «결과와 상관없이 이 처방인 이유»를 내 말로
- 두 번 돌리면 달라진다 → 11-8. `/따라잡기 W3-목-3`
