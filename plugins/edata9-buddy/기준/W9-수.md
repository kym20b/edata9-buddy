# W9-수 기준 — 34장 남에게 보여주는 사례 · 내 플러그인

체크아웃 캡처: 다른 폴더에서 `/[내 플러그인 이름]:진단` 이 보이는 화면 + validate 통과

## 점검 항목

| 항목 | 통과 조건 |
|---|---|
| 독자 · 사례 | `portfolio/독자.md` 와 `portfolio/사례.md` 가 있다 |
| 마켓플레이스 | `edata9-work/my-plugins/.claude-plugin/marketplace.json` 이 있고 `plugins` 에 하나 이상 |
| 플러그인 | `my-plugins/plugins/` 아래 폴더에 `.claude-plugin/plugin.json` 이 있다 — `name` 이 영문 소문자와 `-` |
| 묶은 것 | 그 폴더에 `skills/` 나 `agents/` 가 있고, 안에 하나 이상 |
| 넣지 않은 것 | 그 폴더에 `hooks/` · `hooks.json` · `.mcp.json` · `.env` · `data/` 가 **없다** |
| validate | 확인 불가 — 캡처로 확인 |

## 미흡일 때

- 훅이 들어 있다 → 뺀다(34-10 «훅을 넣지 않는 이유»)
- `plugin.json` 이름에 한글이 있다 → 영문 소문자와 `-` 로
