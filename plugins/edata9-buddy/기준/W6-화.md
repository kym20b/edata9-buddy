# W6-화 기준 — 차이를 믿기 전에: 세 가지 점검을 노트북으로 세운다

체크아웃 캡처: 노트북 화면(슬라이더와 ①) + 보고서 HTML + 9절 iOS 대 Android의 ② 층화 비교 화면

## 점검 항목

| 항목 | 통과 조건 |
|---|---|
| 작업 폴더 | `edata9-work/group-compare/` 가 있고, 옆에 5주의 `metric-dictionary/data/` 가 있다 |
| 공식 스킬 | `group-compare/.claude/skills/statistical-analysis/SKILL.md` 가 있고 머리말에 `user-invocable: false` 가 있다 |
| 노트북 | `group-compare/group_compare.py` 가 있고 `marimo` 노트북이다(`import marimo` 또는 `marimo.App`) |
| 설정 셀 | `group_compare.py` 맨 위 설정에 그룹 둘(`GROUP_A` · `GROUP_B` 같은 이름)과 지표가 있다 |
| 보고서 | `group-compare/group_compare_report.html` 이 있다 |
| 다른 비교 | `group_compare.py` 맨 위 설정의 그룹이 iOS 대 Android(`device_os == 'iOS'` 같은 조건)로 바뀌어 있거나, 그 비교를 돌린 노트북 사본이 있다. 9절 뒤에 다른 비교로 다시 바꿨으면 «확인 불가 — 캡처로 확인» |
| 노트북 화면 · ★ Insight · 4절의 답 | 화면과 대화는 «확인 불가 — 캡처로 확인» |

## 미흡일 때

- 스킬이 없다 → 교안 3절 설치 프롬프트. «승인이 필요해 실행되지 않았다»로 끝났으면 권한 요청에서 `.claude/skills/statistical-analysis` 경로를 보고 Yes를 누른 뒤 «마저 설치해줘»
- 노트북이 없거나 오류가 난다 → 강사가 공유하는 정답본 `group_compare.py` 를 `group-compare` 폴더에 넣는다
- 보고서가 없다 → 교안 8절 프롬프트(코드를 뺀 HTML로 내보내기)
- iOS 대 Android를 안 돌렸다 → 교안 9절 프롬프트. 맨 위 설정만 바꾸고 다른 셀은 고치지 않는다. 월 청구액은 `sum` 이 아니라 `mean`
