# W5-화 기준 — 17장 같은 이름, 다른 숫자: 지표를 정의한다

체크아웃 캡처: 다섯 숫자를 대조한 표(교안 5절) + 내 이탈률 정의서(결정 기록) + `인사이트_화.md`

## 점검 항목

| 항목 | 통과 조건 |
|---|---|
| 목업 | `edata9-work/metric-card/` 에 `index.html` · `metric.js` · `metrics/이탈률.json` · `data/customers_min.csv` 가 있다 |
| 새 판 목업 | `metric-card/app.js` 에 «정의서의 기본값» 이 들어 있다 — 없으면 옛 zip(카드가 프리셋 A로 열린다). 미흡으로 치고 새 zip 안내 |
| 정의서 | `my-wiki/decisions/` 에 이름에 «이탈» 이 든 결정 기록이 있고 «분자» · «분모» · «최소 표본» 이 들어 있다 |
| 버린 정의 | 그 기록에 «버린» 이 든 절이 있고 비어 있지 않다 |
| 인사이트 | `metric-card/인사이트_화.md` 에 «본 것» · «검증» · «그래서» · «확인 안 된» 이 모두 있다 |
| 카드는 그대로 | `metric.js` 가 목업과 같다 (모르면 «확인 불가») |

## 미흡일 때

- 옛 목업이다 → 과정에서 다시 받은 `W5_목업_w5-metric-card.zip` 으로 새로 복사(정의서 · 인사이트는 옮겨 둔다)
- 버린 정의가 없다 → 교안 8절. A~E 가운데 쓰지 않을 것 하나와 그 이유
- 인사이트의 «그래서» 가 «(미정)» 이다 → 교안 9절 인사이트 리포트의 «그래서»
