# W5-화 기준 — 지표 정의와 지표 사전 (활성 고객)

체크아웃 캡처: 앱의 «활성 고객 비율» 카드(정의서 완성) + 12절의 답 첫 줄 + 13절의 대답 두 문장

## 점검 항목

| 항목 | 통과 조건 |
|---|---|
| 목업 | `edata9-work/metric-dictionary/` 에 `index.html` · `app.js` · `metrics/` · `data/` 가 있다 — 없으면 «확인 불가(목업을 받지 않음)» |
| 데이터 확인 스킬 | `metric-dictionary/.claude/skills/explore-data/SKILL.md` 가 있다 |
| 활성 고객 정의서 | `metric-dictionary/metrics/활성_고객_비율.json` 이 있고 `metrics/index.json` 에 이 이름이 있다 |
| 버린 이유 | 그 정의서의 `rejected` 항목마다 `reason` 이 비어 있지 않다(`"reason": ""` 가 없다) |
| 지표 규칙 | `metric-dictionary/CLAUDE.md` 에 «지표 정의» 규칙이 있다 |
| 카드와 대답 | 앱 카드 · 12절의 답 첫 줄 · 13절의 대답은 «확인 불가 — 캡처로 확인» |

## 미흡일 때

- 정의서가 없다 → 교안 9절 프롬프트를 새 대화에서 보낸다. 파일 이름은 `활성_고객_비율.json`
- 버린 이유가 비어 있다 → 교안 10절의 이유 프롬프트를 보낸다(내가 말한 이유만 채운다)
- `CLAUDE.md`에 규칙이 없다 → 교안 11절 프롬프트를 보낸다
- `explore-data`가 없다 → 교안 4절의 설치 프롬프트를 보낸다
