# W7-화 기준 — 25장 앱의 뼈대

체크아웃 캡처: «실행» 화면의 표 12개와 행 수 + 새 대화가 규칙과 «아직 안 정한 것»을 읊는 화면

## 점검 항목

| 항목 | 통과 조건 |
|---|---|
| 골격 | `edata9-work/my-report/` 에 `app.py` · `core/config.py` · `.claude/hooks/after_edit.py` 가 있다 |
| 데이터 | `my-report/data/` 에 parquet 이 12개 있다 |
| 내 결정 | `core/config.py` 의 `FUNNEL_GRAIN` · `VALID_FROM` · `VALID_TO` 가 `None` 이 아니다 |
| 근거 | 그 값들 근처에 `[근거]` 주석이 있다 |
| 규칙 파일 | `my-report/CLAUDE.md` 의 «내가 정한 판단»에 «(미정)»이 아닌 줄이 하나 이상 |
| 데이터는 올리지 않는다 (아직) | `my-report/.gitignore` 에 `*.parquet` 또는 `data/*` 가 있다 |

## 미흡일 때

- 값이 `None` 이다 → 25-9. 결정 기록이 없으면 `기본결정.md`
- 규칙 파일이 그대로다 → 25-10
