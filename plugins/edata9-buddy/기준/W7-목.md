# W7-목 기준 — 27장 대시보드와 임계값 · `chart-rules`

체크아웃 캡처: 내 임계값으로 «주의»나 «미확인»이 뜬 카드 + 스킬이 되묻는 화면

## 점검 항목

| 항목 | 통과 조건 |
|---|---|
| 임계값 | `my-report/core/config.py` 의 `THRESHOLDS` 가 비어 있지 않다 |
| 근거 | 임계값마다 `why` 가 있다 |
| 미확인 | 선을 긋지 않은 지표가 하나 이상 있다 — 없으면 «방향을 단정할 수 없는 지표가 없었나» 물어본다(미흡 아님) |
| 스킬 | `my-report/.claude/skills/chart-rules/SKILL.md` 가 있고, 맨 위에 `description:` 이 있다 |
| 지킬 수 없으면 | 본문에 «만들지 말고» 또는 같은 뜻의 줄이 있다 |

## 미흡일 때

- 임계값에 근거가 없다 → 27-5. 출처를 댈 수 없는 바깥 기준은 근거가 아니다
- 스킬이 없다 → 27-12
