# W1-화 기준 — 내 컴퓨터에 작업실을 차린다

체크아웃 캡처: 설치 점검표 + `주제.md` 의 내용

이날은 수강생이 Claude Code 없이 설치만 한다. 이 점검은 다음 날(W1-수) 로그인한 뒤 `/체크 W1-화` 로 한다.

## 점검 항목

| 항목 | 통과 조건 |
|---|---|
| 작업 폴더 | `edata9-work/` 안에 `캡처/` · `data/` · `gam-test/` 가 있다 |
| 공용 데이터 | `edata9-work/data/` 에 `.parquet` 파일이 12개 있다 |
| 감 테스트 폴더 | `edata9-work/gam-test/` (같은 역할의 폴더면 통과)에 `index.html` 과 `topics/` 가 있다 |
| 묻는 방식으로 시작 | `gam-test/.claude/settings.json` 이 있다 (목업에서 받은 것) |
| 주제 | `gam-test/주제.md` 가 있고 비어 있지 않다 — 후보 셋 |
| 설치 | 확인 불가 — 점검표 캡처로 확인 (Python · Git · GitHub CLI 는 파일만으로는 볼 수 없다) |
