# W2-수 기준 — 6장 분류 기준은 사람이 정한다

체크아웃 캡처: «기준» 탭에 **내 이름(owner) · 올린 version · 고친 내용**이 보이는 화면

## 점검 항목

| 항목 | 통과 조건 |
|---|---|
| 기준의 주인 | `classifier/criteria.json` 의 `owner` 가 목업 문장(«이 기준은 사람이 정했습니다…»)에서 바뀌어 사람 이름이 들어 있다 |
| 버전 | `criteria.json` 의 `version` 이 목업의 1보다 크다 |
| 칸 이름은 그대로 | `categories` 의 이름이 여섯 개 — 해지관련 · 앱기능 · 서비스 · 품질 · 요금 · 기타 |
| 저장 지점 | `classifier` 에 기준을 고친 커밋이 있다 |

## 미흡일 때

- owner · version 을 안 바꿨다 → 책 6-11 요구사항 3 · 4
- 칸 이름이 바뀌었다 → 되감기, 또는 `/따라잡기 W2-수-4`
