# W3-토 기준 — 빈 폴더에서, 내 정리기를 처음부터

체크아웃 캡처: 내 정리기의 정답 대조 화면 + 포트폴리오 3주 칸 + (과제 2를 했다면) 대시보드

## 점검 항목

| 항목 | 통과 조건 |
|---|---|
| 내 데이터 | `my-cleaner/data/` 에 표 파일(.xlsx · .csv)이 하나 이상 있다 |
| 정답은 따로 | `my-cleaner/tools/answer/` 에 파일이 하나 이상 있다 |
| 진단 | `my-cleaner/진단/` 에 진단 파일이 있다 — 이름은 느슨하게 본다 |
| 처방 | `my-cleaner/rules/` 에 데이터 파일과 같은 이름의 `.json` 이 있다 |
| 정리기 화면 | `my-cleaner/index.html` 이 있고, `my-cleaner/lib/` 에 엑셀을 읽는 `.js` 파일이 있다 |
| 원격 | `my-cleaner` 의 원격이 `github.com` 이다 |
| 저장소에 정답 없음 | `git -C my-cleaner ls-files` 목록에 `tools/` 와 `진단/` 아래 파일이 하나도 없다 |
| 포트폴리오 3주 칸 | `portfolio/portfolio.json` 의 week 3 칸이 «엑셀 정리기»(금요일 칸)에서 바뀌었다 — title 이나 url 이 다르면 통과. 느슨하게 본다 |
| 토요일 기록 | `my-wiki/log/` 에 «토요일 프로젝트»가 적힌 기록이 있다 |
| 대시보드 (과제 2) | `my-data/대시보드/app.py` 가 있다. 없으면 «과제 2는 하지 않음»으로 적고 미흡으로 세지 않는다 |

## 미흡일 때

- 내 데이터가 없다 → 교안 1단계의 프롬프트. 주제가 없으면 예시(출장비 정산) 그대로
- 진단이 없다 → 3단계. 스킬 폴더를 복사하고 Reload Window 뒤 `/진단 data/<내 파일>`
- 처방 파일 이름이 다르다 → 데이터 파일 이름과 같게(`rules/<내 파일 이름>.json`)
- `lib/` 가 비어 있다 → "SheetJS 를 내려받아도 된다. lib/ 에 넣어줘"
- 저장소에 `tools/` 가 있다 → 7단계 프롬프트. 아직 올리지 않았다면 이력을 새로 시작하게 한다. 이미 올렸다면 강사에게
- 포트폴리오 3주 칸이 그대로다 → 8단계 프롬프트. 칸을 더하지 말고 바꾼다

## 보지 않는 것

- 처방이 맞게 일했는지, 정답과 몇 줄이 같은지는 보지 않는다. 교안 5 · 6단계의 숫자가 증거다
- 정답 파일(`tools/answer/`)은 열지 않는다
