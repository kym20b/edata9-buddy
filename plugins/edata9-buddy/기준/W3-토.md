# W3-토 기준 — 내 주제의 지저분한 엑셀을, 내 스킬로

체크아웃 캡처: 내 파일의 진단표 + 정답과 대조한 화면

## 점검 항목

| 항목 | 통과 조건 |
|---|---|
| 내 데이터 | `cleaner/data/` 에 목업 예시(상담이력 · 교육이수로그) 말고 표 파일이 하나 이상 있다 |
| 정답은 따로 | `cleaner/tools/answer/` 에 목업 정답 둘 말고 파일이 있다 — 배포에서 빠지는 자리 |
| 진단 | `cleaner/진단/` 에 그 데이터의 진단 파일이 있다 — 이름은 느슨하게 본다 |
| 내 규칙 | `cleaner/rules/` 에 그 데이터 이름의 규칙 파일이 있다 |
| 토요일 기록 | `my-wiki/log/` 에 «토요일 프로젝트»가 적힌 기록이 있다. 없으면 «미흡 — 기본 9단계» (최소 단계라면 미흡이어도 된다) |

포트폴리오 3주 칸은 점검하지 않는다. 바꿀지는 학생이 고른다.

## 미흡일 때

- 내 데이터가 없다 → 교안 1단계의 프롬프트. 주제가 없으면 예시(출장비 정산) 그대로
- 진단이 없다 → `/진단 data/<내 파일>`. `/진단` 이 없으면 `/따라잡기 W3-수-4`
- 규칙 파일 이름이 다르다 → 데이터 파일 이름과 같게(`rules/<내 파일 이름>.json`)
