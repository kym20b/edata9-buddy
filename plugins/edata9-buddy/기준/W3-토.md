# W3-토 기준 — 혼자 해보기 · 내 스킬로 처음 보는 파일

체크아웃 캡처: `/진단 ../messy/마케팅집행.xlsx` 의 진단표 + 노션 «3주» 장

## 점검 항목

| 항목 | 통과 조건 |
|---|---|
| 처음 보는 파일의 진단 | `cleaner/진단/` 에 마케팅집행의 진단 파일이 있다 — 이름은 느슨하게 본다 |
| 내 규칙 | `cleaner/rules/` 에 목업에 없던 규칙 파일이 있다 — 최소 완주라면 교육이수로그의 처방 하나가 바뀌었으면 통과 |
| 판단 기준 | `my-wiki/판단기준.md` 에 «3주» 장이 있다 |
| 노션 | 이어져 있으면 «EDATA 주간 노트»에 «3주»가 있는지 본다. 아니면 «확인 불가(노션 미연결)» |

## 미흡일 때

- 진단 파일이 없다 → 혼자 해보기 1번. `/진단` 이 없으면 `/따라잡기 W3-수-4`
- 노션이 안 이어진다 → 2주 토의 노션 순서. 다음 토요일에 해도 된다
