# W5-토 기준 — 중간 축제 · 리셋 지점

체크아웃 캡처: 내 지표 셋의 정의서(최소: 한 요소를 바꾼 정의서) + 노션 «지표 사전» 둘 이상

## 점검 항목

| 항목 | 통과 조건 |
|---|---|
| 지표 정의서 | `my-wiki/decisions/` 에 지표 정의 기록이 둘 이상 — 최소 완주라면 이탈률 하나와 바뀐 요소 |
| 판단 기준 | `my-wiki/판단기준.md` 에 «5주» 장이 있다 |
| 리셋 | `edata9-work/data/` 에 parquet 이 12개 있다 — 6주가 이것을 읽는다 |
| 노션 | 이어져 있으면 «지표 사전»의 줄 수를 본다. 아니면 «확인 불가(노션 미연결)» |

## 미흡일 때

- 공용 데이터가 없다 → 강사에게 압축본을 받는다. 6주 21장 «먼저 해 봅니다»가 이것을 읽는다
