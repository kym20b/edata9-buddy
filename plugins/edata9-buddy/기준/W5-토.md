# W5-토 기준 — 중간 축제 · 내 업무 지표 셋 · 리셋 지점

체크아웃 캡처: 내 지표 정의서 셋(최소: 하나) + 다시 센 분자 · 분모 + 노션 «지표 사전» 둘 이상

## 점검 항목

| 항목 | 통과 조건 |
|---|---|
| 지표 정의서 | `my-wiki/decisions/` 의 결정 기록이 셋 이상 — 이탈률 · 재문의율에 내 지표 하나(최소). 다섯 이상이면 내 지표 셋(기본) |
| 정의서의 여섯 요소 | 새 정의서마다 «분자» · «분모» · «최소 표본» 이 들어 있다 |
| 판단 기준 | `my-wiki/판단기준.md` 에 «5주» 장이 있다 |
| 토요일 기록 | `my-wiki/log/` 에 기록이 하나 이상 |
| 리셋 | `edata9-work/` 에 `metric-card` · `my-wiki` · `portfolio` 가 있다 — 6주가 이 폴더들을 이어 쓴다 |
| 노션 | 이어져 있으면 «지표 사전»의 줄 수를 본다. 아니면 «확인 불가(노션 미연결)» |

## 미흡일 때

- 정의서가 모자란다 → 교안 과제 1의 2단계. 스킬 `지표` 가 이 폴더에 없으면 «../metric-card/.claude/skills/지표 를 이 폴더로 복사해줘» → Reload Window
- 스킬이 «유효 구간을 조회하지 못했다»며 멈췄다 → 정상. 정산 표에 날짜가 없다 — 내가 기준을 정해 답한다
- 밀렸다 → `/따라잡기 W5-금` 으로 금요일 끝 상태를 받아 6주를 시작한다
