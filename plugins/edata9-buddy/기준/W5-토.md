# W5-토 기준 — 내 데이터로, 내 지표 사전을 처음부터

체크아웃 캡처: 내 지표 사전의 카드(정의서 id · 분자 ÷ 분모) + 새 대화의 답 첫 줄 + `erd.html` 그림 + (선택) 대시보드

## 점검 항목

| 항목 | 통과 조건 |
|---|---|
| 앱 틀 | `edata9-work/my-metrics/` 에 `app.js` · `metrics/index.json` · `data/` 가 있다 |
| ERD | `my-metrics/erd.html` 이 있고 `erDiagram` 이 들어 있다 |
| 내 지표 정의서 | `my-metrics/metrics/` 에 정의서가 하나 이상(최소) — `index.json` 을 빼고 셀 때. 셋 이상이면 기본 |
| 내 업무 데이터 스킬 | `my-metrics/.claude/skills/` 에 복사해 온 네 스킬(data-context-extractor · explore-data · validate-data · 정의점검) 말고 내가 만든 스킬이 하나 있다 |
| 판단 기준 | `my-wiki/판단기준.md` 에 «5주» 장이 있다 |
| 배포 | `my-metrics` 의 git 원격이 `github.com` 이다 |
| 카드 · 새 대화의 답 · 대시보드 | 화면과 대화는 «확인 불가 — 캡처로 확인» |

## 미흡일 때

- 앱 틀이 없다 → 교안 2단계 프롬프트. `../metric-dictionary` 와 `../my-window` 가 `edata9-work` 안에 있어야 한다. 지난주 `my-window` 가 없으면 강사가 공유한 도메인 목업 하나를 `my-window` 로 쓴다
- 카드 값이 Claude 답의 100배다 → 정의서에 `"scale": 1` 이 없다. «카드 값이 100배로 나와. app.js 의 scale 규칙을 보고 고쳐줘»
- 정의서가 없다 → 교안 4단계(지표 후보) 다음 5단계 프롬프트. 여섯 요소와 버린 정의는 내가 정해 적는다
- 내 업무 데이터 스킬이 없다 → 교안 8단계. `.claude` 쓰기 권한 요청에서 경로를 보고 Yes
- 밀렸다 → `/따라잡기 W5-금` 으로 금요일 끝 상태를 받아 6주를 시작한다
