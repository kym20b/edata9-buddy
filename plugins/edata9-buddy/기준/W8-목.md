# W8-목 기준 — 31장 버튼 하나로 대신 돌린다

체크아웃 캡처: Actions 버튼으로 돌려 내 디스코드에 온 브리핑과 PDF

## 점검 항목

| 항목 | 통과 조건 |
|---|---|
| 원격 | `briefing-bot` 의 원격이 `github.com` 이다 |
| 버튼 | `.github/workflows/briefing.yml` 에 `workflow_dispatch` 가 있다 |
| 비밀은 Secrets 에서 | 작업 파일의 웹훅 · 열쇠가 `secrets.` 로 꺼내진다 |
| 주소가 저장소에 없다 | 저장소의 파일 어디에도 `discord.com/api/webhooks` 가 없다 (찾으면 파일 이름만) |
| 결과는 올라가지 않는다 | `out/` 의 파일이 커밋돼 있지 않다 |
| Secrets · 디스코드 | 확인 불가 — 캡처로 확인 |

## 미흡일 때

- 주소가 저장소에 있다 → **디스코드에서 그 웹훅을 지우고** 새로 만든다. 그다음 기록을 정리한다
