# W2-금 기준 — 8장 AI를 채점한다

체크아웃 캡처: 채점 탭 — **규칙과 AI의 점수가 나란히** + 포트폴리오 **둘째 칸**

## 점검 항목

| 항목 | 통과 조건 |
|---|---|
| AI 채점 결과 | `classifier/ai_채점결과.json` 이 있다 (키가 없어 규칙만 쟀다면 «확인 불가») |
| 잰 조건 | `my-wiki/log/` 에 날짜 이름의 기록이 하나 이상 있다 |
| 결정 기록 | `my-wiki/decisions/` 에 기록이 둘 이상 있다 |
| 판단 기준 | `my-wiki/판단기준.md` 에 «2주» 장이 있다 |
| 포트폴리오 둘째 칸 | `portfolio/portfolio.json` 의 `cards` 가 둘 이상이다 |

## 미흡일 때

- AI 채점이 안 됐다 → 규칙 채점만으로 기본 완료. 8-10은 규칙 채점의 «틀린 문장»으로 연습한다
- 포트폴리오가 없다 → 1부 4-11 (2주부터 시작해도 된다)
