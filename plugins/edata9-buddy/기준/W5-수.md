# W5-수 기준 — 조인과 지표 조합 (월 청구 합계 · 고객당 매출)

체크아웃 캡처: 앱의 «고객당 매출» 카드와 계보 탭 + 11절의 답 첫 줄 + 12절의 대답 두 문장

## 점검 항목

| 항목 | 통과 조건 |
|---|---|
| 정의서 둘 | `metric-dictionary/metrics/월_청구_합계.json` · `월말_유지_고객_수.json` 이 있고 `metrics/index.json` 에 이름이 있다 |
| 파생 정의서 | `metrics/고객당_매출.json` 이 있고 `"kind": "derived"` 와 `inputs` 가 들어 있다 |
| 입력 정의서 수정 | `metrics/월_청구_합계.json` 에 «월말 유지 고객» 이 들어 있다 — 10절에서 분자의 대상을 분모와 맞췄다 |
| 그림 스킬 | `metric-dictionary/.claude/skills/create-viz/SKILL.md` 가 있다 |
| 그림 | `metric-dictionary/` 에 `월말유지_두기준` 으로 시작하는 png 가 있다 |
| 카드 · 계보 · 새 대화의 답 | 앱 화면과 대화는 «확인 불가 — 캡처로 확인» |

## 미흡일 때

- 정의서 둘이 없다 → 교안 7절 프롬프트를 새 대화에서 보낸다(파일 이름은 `월_청구_합계.json` · `월말_유지_고객_수.json`)
- 고객당 매출이 파생 정의서가 아니다 → 교안 8절 프롬프트. «계산 SQL: 쓰지 마… inputs로 가져다 쓰게 해» 줄을 빼지 않는다
- 월 청구 합계에 «월말 유지 고객»이 없다 → 교안 9절의 점검 뒤 10절 프롬프트로 입력 정의서를 고친다
- 그림이 없다 → 교안 6절 `create-viz` 프롬프트. 한글이 □ 이면 «한글이 깨지지 않게 해줘»
