# W5-수 기준 — 18장 언제부터 믿을 수 있나: 기간과 유효 구간

체크아웃 캡처: 그래프 두 개(0으로 채운 것 · 선을 끊은 것)를 나란히 + 재문의율 정의서 + `인사이트_수.md`

## 점검 항목

| 항목 | 통과 조건 |
|---|---|
| 정답 원장 | `edata9-work/cleaner/tools/answer/상담원장_2025_정답.csv` 가 있다 — 없으면 «확인 불가(3주 금 정답 파일 없음)» |
| 그래프 둘 | `metric-card/` 에 `그래프_` 로 시작하는 png 가 둘 이상 |
| 재문의율 정의서 | `my-wiki/decisions/` 에 이름에 «재문의» 가 든 결정 기록이 있고 «유효 구간» 이 들어 있다 |
| 조회한 날짜 | 그 기록에 `2025-03-01` 이 있다 — 데이터로 확인한 첫 기록 날짜 |
| 인사이트 | `metric-card/인사이트_수.md` 에 «본 것» · «검증» · «그래서» · «확인 안 된» 이 모두 있다 |

## 미흡일 때

- 유효 구간이 짐작이다 → 교안 3절 «세 가지 확인» 프롬프트로 첫 기록 날짜를 조회
- 그래프 한글이 □ → «맑은 고딕(Malgun Gothic)으로 다시 그려줘»
- 그래프의 세로축이 서로 다르다 → «두 그래프 세로축을 0~30%로 똑같이»
