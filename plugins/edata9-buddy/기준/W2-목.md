# W2-목 기준 — 7장 열쇠를 숨기는 자리 (+ 잠금 · 검문)

체크아웃 캡처: **훅이 커밋을 막은 화면** («검문 훅이 막았습니다 — …») + Vercel 주소에서 «AI»로 분류된 카드

## 점검 항목

| 항목 | 통과 조건 |
|---|---|
| 잠금 | `classifier/.claude/settings.json` 의 `permissions.deny` 에 `Read(.env)` 가 있다 |
| 검문 | 같은 파일의 `hooks.PreToolUse` 에 `block_secrets.py` 를 부르는 훅이 있다 |
| 훅 프로그램 | `classifier/.claude/hooks/block_secrets.py` 가 있다 |
| 열쇠가 코드에 없다 | `classifier` 의 `.js` · `.py` · `.json` 파일 어디에도 `AIza` 로 시작하는 값이 없다 (찾으면 값은 적지 말고 파일 이름만) |
| `.env` 는 올라가지 않게 | `classifier/.gitignore` 에 `.env` 가 있다 |
| 원격 | `classifier` 의 원격이 `github.com` 이다 |
| Vercel 설정 | 확인 불가 — 캡처로 확인 |

## 미흡일 때

- 잠금이나 검문이 없다 → 책 7-14 · 7-15. 막히면 `/따라잡기 W2-목-4` · `/따라잡기 W2-목-5`
- 코드에서 열쇠가 나왔다 → **그 열쇠를 먼저 폐기**(7-6), 그다음 지운다
- 원격이 없다 → 1부 4-9처럼 Claude에게 «GitHub CLI(gh)로 이 저장소를 내 GitHub에 공개 저장소로 만들고 올려줘» — 묻는 화면을 읽고 허락한다
