# 따라잡기 — 그 지점부터 다시

받은 인자: $ARGUMENTS

## 1. 태그로 바꾼다

| 인자 | 태그 |
|---|---|
| `W1-수` | `w1-wed-end` (그날 끝) |
| `W1-수-3` | `w1-wed-3` (그날 세 번째 체크포인트) |

요일: 화 → `tue` · 수 → `wed` · 목 → `thu` · 금 → `fri` · 토 → `sat`. 주 번호는 소문자 `w` 뒤에. 인자가 비었거나 모양이 다르면 «예: /따라잡기 W1-수 또는 /따라잡기 W1-수-3» 이라고만 말하고 멈춘다.

## 2. 저장소 주소

`${CLAUDE_PLUGIN_ROOT}/설정.json` 의 `snapshot_repo`.

## 3. 가져온다 — 덮어쓰지 않는다

1. 지금 폴더 아래 `_따라잡기/<인자>/` 가 **이미 있으면 멈추고** «이미 가져온 적이 있습니다. 지우고 다시 가져올까요?» 라고 묻는다.
2. 없으면 이것 **하나만** 실행한다.
   `git clone --depth 1 --branch <태그> <snapshot_repo> "_따라잡기/<인자>"`
3. 태그가 없다고 나오면 `git ls-remote --tags <snapshot_repo>` 로 있는 태그를 보고, 같은 주의 태그만 골라 보여 준 뒤 멈춘다.
4. **`_따라잡기/` 밖의 파일은 만들거나 고치거나 지우지 않는다.** 내 작업 폴더에 옮겨 붙이는 것은 학생이 고른 뒤에 한다.

## 4. 가져온 뒤

`_따라잡기/<인자>/따라잡기.md` 가 있으면 읽고 그대로 보여 준다 — 그 지점의 상태와 이어 가는 법이 적혀 있다. 없으면 폴더의 맨 위 목록만 보여 주고 이렇게 덧붙인다.

```
이 폴더가 <인자> 시점의 상태입니다.
이어 가는 길은 둘입니다 — 이 폴더에서 Claude Code를 켜서 그대로 이어 가거나,
내 폴더와 다른 파일을 «비교해서 보여줘» 로 보고 필요한 것만 옮깁니다.
```
