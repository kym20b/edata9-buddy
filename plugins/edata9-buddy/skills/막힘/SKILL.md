# 막힘 — 막혔을 때의 순서

받은 증상: $ARGUMENTS

## 1. 회차를 정한다

`${CLAUDE_PLUGIN_ROOT}/일정.json` 과 지금 날짜로 회차를 찾는다. 증상에 `W1-화` 같은 회차가 적혀 있으면 그것을 쓴다. 못 찾으면 회차 없이 공통 표만 본다.

## 2. 준비된 표에서 찾는다

`${CLAUDE_PLUGIN_ROOT}/막힘/<회차>.md` 를 먼저, 그다음 `${CLAUDE_PLUGIN_ROOT}/막힘/공통.md` 를 읽는다. 증상이 비어 있으면 «무엇을 하려다 무엇이 떴는지, 오류는 요약하지 말고 그대로 붙여 주세요» 라고만 말하고 멈춘다.

**표의 범위 안에서만 답한다.** 표에 없는 증상을 추측해서 원인을 지어내지 않는다. 지금 대화에서 보이는 파일 · 오류 메시지는 읽어도 되지만, 고치지는 않는다.

## 3. 이 모양으로만 답한다

```
원인        (표의 «원인» — 한 줄)
그 자리에서  (표의 «그 자리에서» — 할 일 하나)
안 되면     (표의 «안 되면»)
            고치지 못해도 진도는 따라갑니다 — /따라잡기 W○-○-N 으로 그 지점부터

그래도 막히면 → 수업 중이면 줌에서 손을 들고 강사에게 화면을 보여 주세요
수업 뒤라면 디스코드 질문 채널에 → [체크포인트] 무엇을 하려다 · 무엇이 떴나 · /막힘 에서 해 본 것
```

표에서 못 찾았으면 위 세 줄 대신 «준비된 표에 없는 증상입니다» 라고 쓰고, 질문 양식을 **학생의 증상으로 채워서** 보여 준다.

## 지킬 것

- **열쇠(API 키) · 웹훅 주소 같은 값이 증상에 섞여 있으면, 그 값을 다시 적지 않는다.** «그 값은 이미 보낸 것이니 먼저 폐기하고 새로 받으세요(7-6)» 를 맨 위에 쓴다.
- 파일을 만들거나 고치거나 명령을 실행하지 않는다. 학생이 «그렇게 해줘» 라고 하면 그때 한다.
- 꾸짖거나 재촉하지 않는다. 막히는 것은 정상이다.
