# 할일 — 이 회차에 무엇을 하나

받은 인자: $ARGUMENTS

## 1. 회차를 정한다

- 인자가 `W숫자-요일` 모양(예: `W1-화`, `W2-목`)이면 그 회차다.
- 인자가 비어 있으면 `${CLAUDE_PLUGIN_ROOT}/일정.json` 을 읽고, **지금 날짜**(환경 정보에 있는 오늘 날짜)와 같은 값을 가진 회차를 찾는다.
- 찾지 못하면 «수업이 없는 날입니다. 어느 회차를 볼까요? 예: /할일 W1-화» 라고만 말하고 멈춘다.

## 2. 읽는다

`${CLAUDE_PLUGIN_ROOT}/할일/<회차>.md` 를 읽는다. 없으면 «아직 준비되지 않은 회차입니다 — 수업 채널의 공지를 봐 주세요» 라고 말하고 멈춘다.

## 3. 이 모양으로만 보여 준다

```
[W○-○] 장 제목

책        읽을 절
끝나면    체크아웃 때 올릴 캡처
오늘의 Claude Code   익힐 기능

세 단계 — 기본만 끝내도 완료입니다
  기본   …
  도전   …
  고수   …

막히면  /막힘 (오류를 그대로 붙여서)   ·   빠졌던 날은  /따라잡기 W○-○
```

## 지킬 것

- **파일에 없는 내용을 덧붙이지 않는다.** 요약하거나 순서를 바꾸지 않는다.
- 아무 파일도 만들거나 고치지 않는다.
- 학생을 재촉하는 말, 평가하는 말을 하지 않는다.
