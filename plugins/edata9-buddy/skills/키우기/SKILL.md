# 키우기 — 클로드 코드 데이터 분석 박사 키우기

받은 인자: $ARGUMENTS

모든 계산은 `${CLAUDE_PLUGIN_ROOT}/게임/doctor.py` 가 한다. **너는 스크립트를 부르고, 나온 글 전체를 네 답에 고치지 말고 그대로 옮겨 적는다** — 학생 화면에서 도구 결과는 접혀 있어서, 네 답에 옮기지 않으면 카드가 보이지 않는다. 경험치를 어림하거나 더 주거나, 세이브 파일을 직접 고치지 않는다.

## 1. 인자대로 한 번 부른다

```
python "${CLAUDE_PLUGIN_ROOT}/게임/doctor.py" <인자를 그대로>
```

| 인자 | 하는 일 |
|---|---|
| (비움) | 내 캐릭터 카드 |
| `시작 <이름> <마스코트>` | 캐릭터를 만든다. 이름이나 마스코트가 없으면 **부르기 전에** 묻는다 — 먼저 `doctor.py 마스코트` 로 고를 수 있는 여섯을 보여 주고, 학생이 고른 이름과 마스코트로 부른다 |
| `확인 [W1-화]` | 그 회차의 퀘스트를 검사하고 경험치를 준다. 회차를 비우면 오늘 날짜로 찾는다 |
| `도감` · `도감 <칸>` | 도감 보기 · 칸 하나 채우기 |
| `이름 <새 이름>` | 이름 바꾸기 |
| `올리기` | 세이브를 내 GitHub 공개 저장소 `edata9-doctor` 에 올린다 |

## 2. «스스로 체크» 단계가 남았을 때

`확인` 결과에 «스스로 체크할 단계»가 있으면, **결과 전체를 먼저 옮겨 적은 다음** 그 아래에서 **한 번만** 묻는다 — «이 단계를 해 보셨나요?». 학생이 했다고 답한 단계만 넣어 다시 부른다.

```
python "${CLAUDE_PLUGIN_ROOT}/게임/doctor.py" 확인 <회차> --스스로 <단계…>
```

안 했다고 하면 그대로 끝낸다. 하라고 권하거나 대신 해 주지 않는다.

## 3. `올리기` 앞에서

부르기 전에 한 줄로 알린다 — «세이브(캐릭터 이름 · 레벨 · 퀘스트 기록)를 GitHub 공개 저장소에 올립니다. 반 전체 보드가 이것을 읽습니다.» 처음 올릴 때는 `gh repo create edata9-doctor --public` 이 돈다.

## 지킬 것

- 이 스킬이 만들거나 고치는 것은 `edata9-work/edata9-doctor/` 폴더뿐이다(`character.json` · `캐릭터.svg` · `README.md`). 다른 파일은 건드리지 않는다.
- 순위 · 다른 사람과의 비교 · 칭찬 문구를 덧붙이지 않는다. 스크립트가 낸 글이 전부다.
- 오류가 나면 오류 글을 그대로 보여 주고, 아래 한 줄을 붙인다 — «막히면 `/막힘` 에 이 글을 붙여 주세요.»
