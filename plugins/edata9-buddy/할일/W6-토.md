# W6-토 — 6주 토 — 도메인 실험 데이터로: 판정기를 데이터만 바꿔 쓰고, 내 업무의 실험을 설계한다

> 오늘 교안에서 뽑은 학습자용 요약입니다.

| 항목 | 내용 |
|---|---|
| 책 범위 | 교안 과제 1(1 ~ 5단계 — 도메인 실험 데이터를 판정기에) · 과제 2(6 ~ 8단계 — 내 업무의 가상 실험 설계) |
| 체크아웃 캡처 | 도메인 판정기의 다섯 판정 중 하나 + 노션 «실험 관리»의 판정 완료 행 + 내 가상 실험의 필요 기간 |
| 필수 무기 · 한 수 | 이번 주에 세운 것을 그대로 쓴다 — 판정기는 규칙(`rules.json`) · 엔진(`judge.js`) · 입력(`data/experiments.json`)이 나뉘어 있어 **입력만 바꾼다**. 가드레일은 값과 함께 **방향**(높을수록 좋은가, 낮을수록 좋은가)을 옮긴다. 대상이 적은 업무는 «이 규모로는 검출할 수 없다»고 먼저 말하는 것이 판정이다. 강사가 나눠 준 도메인 zip 둘(`W4토_앱만들기_도메인N_…` · `W6토_실험데이터_도메인N_…`) |
| 미션 세 단계 | 최소 = 과제 1의 1 ~ 4단계(데이터 받기 · 판정기 사본 `my-judge` · 입력 파일 · 화면에서 다섯 판정) · 기본 = 과제 1 전체(노션에 판정 완료 다섯 행) + 과제 2(내 가상 실험을 노션에 «설계 중»으로) · 도전 = 통계검산관을 이 데이터에 맞춰 다섯 판정을 다시 센다 |
