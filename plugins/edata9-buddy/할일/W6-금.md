# W6-금 — 6주 금 — 규모 계산과 배포: 판정기에 «필요 인원 · 기간» 탭을 더해 인터넷에 올린다

> 오늘 교안에서 뽑은 학습자용 요약입니다.

| 항목 | 내용 |
|---|---|
| 책 범위 | 교안 1 ~ 9절 (1교시 필요 인원 · 기간 · 판정을 회의 문장으로 · 2교시 계산 탭 추가 · 배포 · 3교시 기준값 바꾸기 · 개념 정리 · 판단 한 장) |
| 체크아웃 캡처 | 배포한 URL의 «필요 인원 · 기간» 탭 + 개념 정리 아티팩트 + 판단 한 장 «6주» |
| 필수 무기 · 한 수 | 오늘의 개념 — **찾을 차이(MDE)가 필요 인원과 기간을 정한다**(차이를 절반으로 줄이면 인원은 약 네 배). 계산 탭에는 새 공식을 쓰지 않고 판정기 엔진(`judge.js`)의 함수와 **`rules.json`** 의 기준값을 읽는다. 새로 설치하는 스킬은 없다. 7절은 아티팩트 «6주 개념 정리»로 본다 |

## 세 단계 — 기본만 끝내도 완료

| 단계 | 무엇 | 끝나면 |
|---|---|---|
| 기본 (필수) | 필요 인원 그래프 + 판정 문장 + 탭 추가 + 나가는 파일 + 배포 + 기준값 바꾸고 되돌리기 + 개념 정리 + 판단 한 장 «6주» | 체크아웃 |
| 도전 | «필요 인원 · 기간» 탭에 «찾을 차이를 입력해 보기» 입력란을 더하되, 처음 값은 `rules.json` 에서 읽게 한다. 판정 탭의 기준은 바꾸지 않는다 | 기준과 탐색이 나뉜 계산 탭 |
| 고수 | 수요일 노션 «실험 관리»의 «필요한 표본과 기간»을 판정기 탭으로 다시 계산해 노션 값과 맞는지 Claude에게 대조시킨다 | 노션과 판정기가 같은 기준인지 확인 |
