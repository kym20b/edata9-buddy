# W4-토 — 4주 토 — 작업 모임 · 내 주제의 표 여러 개로, 내 창을

> 진행안에서 뽑은 학습자용 요약입니다. 고치지 말고 진행안을 고친 뒤 `_build/make_buddy.py` 로 다시 뽑습니다.

| 항목 | 내용 |
|---|---|
| 책 범위 | 4부 혼자 해보기 (내 주제로 · 최소 완주 경로 · 막히면) · 도전은 14-8 방식 BigQuery · 부록 E-6은 참고 |
| 체크아웃 캡처 | 내 창(`my-window`)의 «준비한 질문» — 표 둘 이상을 붙인 질문 하나 + 정답과 대조한 표 |
| 미션 세 단계 | 최소 = 1~5(내 표 셋 · 정답 잠금 · 한 줄 · 질문 · 계획대로 붙여 줄 수 대조) · 기본 = 1~9(창에 넣고 정답과 견주고 올리고 위키) · 도전 = 내 표 하나를 BigQuery에 올려 같은 SQL로 같은 답 |
| 필수 (전원) | 위키 `log/` 에 «토요일 프로젝트 · 내 주제» 기록 · 포트폴리오 4주 칸은 **선택** |
